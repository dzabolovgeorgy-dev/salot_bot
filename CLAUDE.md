# salon-bot

ИИ-администратор для салона красоты через Telegram Mini App (TWA).

## Функционал
- Запись клиентов на услуги
- Выбор мастера
- Напоминания о записи
- Ответы на частые вопросы (FAQ)

## Стек
- **Backend**: Node.js, TypeScript, Express (сервер)
- **Бот**: Telegraf (Telegram Bot API)
- **База данных**: SQLite
- **Frontend**: Vite + React (интерфейс внутри Telegram — Mini App/TWA)

## Как объяснять
Пользователь — новичок в программировании, учится вайб-кодингу. Объяснять простыми словами, что делает код, избегать непонятных терминов без расшифровки.

## ОБЯЗАТЕЛЬНОЕ правило (выполнять всегда, для каждой задачи)

ВАЖНО: Пользователь — новичок, не понимает программирование. 
Всегда отвечай ТОЛЬКО на русском языке, без английских слов и фраз.
После завершения любой задачи давай финальное объяснение в конце (не в процессе, 
а именно в самом конце) простыми словами:
1. Что сделано
2. Зачем
3. Что именно изменилось

Без технического жаргона, без английских терминов без перевода, без слов вроде 
"working as designed", "spot-check" и т.п. — только простой русский язык.
